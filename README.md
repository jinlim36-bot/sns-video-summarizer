# SNS 영상 AI 요약기

YouTube 자막 또는 YouTube/Instagram 오디오를 이용해 한국어 요약을 만드는 Streamlit 앱입니다. Gemini API로 음성 인식과 요약을 수행합니다.

## 실행

Python 3.12에서 검증했습니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Gemini 키는 직접 입력한 임시 키, 브라우저에 저장한 키, `GEMINI_API_KEY` 또는 `GOOGLE_API_KEY` 환경변수, Streamlit secrets 순으로 조회합니다. **Gemini API 키 설정** 영역은 항상 표시하며, 현재 사용하는 키의 출처를 안내합니다. 저장 화면이 로드되지 않으면 **저장 화면이 보이지 않으면 직접 입력**에서 이번 접속에 사용할 키를 입력할 수 있습니다. secrets 파일이 없어도 실행할 수 있습니다. 키와 쿠키는 Git에 커밋하지 마세요.

선택 설정:

- `GEMINI_MODEL`: 화면의 모델 선택 목록에 추가할 서버 설정 모델. 기본 선택은 `gemini-3.5-flash-lite`입니다. 기존 서버 설정이 있더라도 화면에서 선택한 모델을 사용합니다.
- `YOUTUBE_COOKIES`: 인증이 필요한 영상에 사용하는 Netscape 형식 쿠키 텍스트. 다운로드 작업의 임시 디렉터리에만 저장하고 작업 종료 시 삭제합니다.

## 동작과 제한

- HTTPS YouTube 영상 및 Instagram 릴스/게시물 URL을 검증합니다. 플레이리스트와 진행 중인 라이브 방송의 오디오 처리는 지원하지 않습니다.
- YouTube 자막이 없는 경우 오디오를 다운로드합니다. 자막 조회 접근 오류는 원인을 숨긴 채 다운로드로 넘어가지 않고 안내합니다.
- 오디오 처리 대상은 60분 이하 영상입니다. 플랫폼 길이 정보가 없으면 다운로드를 진행하고, 변환된 오디오의 실제 길이를 FFmpeg로 확인합니다. 다운로드 중 100MB 제한, 변환 오디오 20MB 제한을 적용합니다. 소켓 타임아웃 및 재시도 제한과 다운로드 진행 시 3분 제한을 적용하지만 전체 작업 시간을 보장하는 제한은 아닙니다.
- 음성 언어는 기본적으로 자동 감지하며 한국어/영어를 선택할 수 있습니다.
- 긴 자막은 나누어 요약한 뒤 합칩니다. 텍스트는 240,000자까지 처리하며 긴 영상은 API 호출 횟수와 비용이 증가합니다.
- 자막의 시간 표시는 보존합니다. 음성 인식 결과에는 시간 표시를 생성하지 않습니다.
- 결과는 세션에 유지되며 Markdown으로 다운로드할 수 있습니다. 새 작업 실패 시 이전 결과와 그 영상 URL이 유지됩니다.
- 영상 공개 여부, 플랫폼의 접근 제한, 네트워크 정책, Gemini 인증 및 사용량 한도에 따라 실제 처리에 실패할 수 있습니다.

## 테스트

```bash
python -m unittest discover -s tests -v
python -m pip check
```

테스트는 외부 API를 대체해 URL 검증, 최신 자막 응답, 자막 오류 구분, 동시 다운로드 파일 격리, 실패 시 정리, 영상 길이 제한, 긴 텍스트 요약, 키 조회와 화면 결과 유지 등을 검증합니다. 실제 외부 영상 다운로드와 Gemini 호출은 유효한 키와 네트워크 접근이 있는 환경에서 별도로 확인해야 합니다.

## Streamlit Cloud 자동 방문

GitHub Actions의 `Keep Streamlit Alive` 워크플로가 2시간마다 브라우저로 앱을 방문합니다. 슬립 화면이면 깨우기 버튼을 누르고, 실제 앱 제목과 요약 버튼이 표시되는지 확인한 뒤 60초 동안 세션을 유지합니다. 요약 버튼을 누르거나 Gemini API를 호출하지 않습니다.

1. 기본 대상은 `https://sns-video-summarizer-hukphapjbrrte5n87fyat9.streamlit.app`입니다. 주소가 바뀌면 GitHub 저장소의 **Settings → Secrets and variables → Actions → Variables**에 `STREAMLIT_APP_URL`을 등록해 덮어쓸 수 있습니다.
2. **Actions → Keep Streamlit Alive → Run workflow**로 수동 실행해 성공 여부를 확인합니다.
3. 기본 브랜치에 워크플로가 있어야 정기 실행됩니다. 저장소에서 Actions가 허용되어 있어야 합니다.

예약 실행은 지연되거나 누락될 수 있고, 공개 저장소는 60일간 저장소 활동이 없으면 예약 워크플로가 비활성화될 수 있습니다. 플랫폼이 자동 방문을 실제 사용자 활동으로 인정하는지도 보장할 수 없으므로 이 작업은 상시 가동을 보장하지 않습니다. 지속 가동이 필수라면 상시 실행을 지원하는 호스팅을 사용하세요. 비공개 앱의 로그인 화면은 이 워크플로로 통과하지 않습니다.

Gemini 요약 입력 한도 오류(413 등)는 입력을 더 작은 구간으로 나누어 제한된 횟수만 재시도합니다. 그 외 모델/권한/서비스 오류는 HTTP 상태와 오류 종류를 안내하며 원문이 포함될 수 있는 API 응답 전문은 표시하지 않습니다.

모델이 없거나 일시 오류 재시도 후에도 응답하지 않으면 계정 모델 목록에서 `generateContent`를 지원하는 대체 Gemini Flash 모델로 전환하고 화면에 표시합니다. 대체 모델은 영상 전체에서 최대 한 번만 선택하며, 목록에도 사용 가능한 후보가 없으면 오류를 표시합니다.

## 브라우저에 API 키 저장

처음 접속할 때 키를 입력하고 **이 브라우저에 저장**을 누르면 다음 접속부터 자동 복원합니다. **저장된 키 삭제**로 지우거나 새 키를 입력해 변경할 수 있습니다. 키는 서버 파일에 보관하지 않고 브라우저 IndexedDB에 AES-GCM으로 암호화해 저장합니다. 암호화 키는 내보낼 수 없는 브라우저 CryptoKey로 보관합니다.

저장 범위는 같은 사이트와 브라우저 프로필입니다. 다른 기기/브라우저, 시크릿 창, 사이트 데이터 삭제 이후에는 재입력이 필요합니다. 저장소가 차단되면 현재 접속에서만 키를 사용한다고 안내합니다. 요약 요청에는 키가 앱 서버로 전달됩니다. 암호화는 공용 PC 사용자나 해당 사이트에서 실행되는 악성 스크립트의 사용을 막지는 못하므로 공용 PC에서는 삭제하세요. 서버 재시작 이후에도 해당 브라우저의 사이트 데이터가 유지되면 복원됩니다.

브라우저 저장 기능 검증은 Playwright를 설치한 환경에서 `python tests/browser_key_smoke.py`로 실행할 수 있습니다. 이 검증은 시스템 Chromium(`/usr/bin/chromium`)을 사용하며 실제 키 대신 테스트 문자열로 암호화 저장·새 페이지 복원·삭제를 확인합니다.

## Gemini로 전환

[Google AI Studio](https://aistudio.google.com/apikey)에서 발급한 Gemini API 키를 입력하세요. 기존 Groq 키는 사용할 수 없으며, 브라우저 저장소도 Gemini용으로 분리되어 자동으로 재사용하지 않습니다. 서버에서 설정하려면 Streamlit Cloud Secrets에 `GEMINI_API_KEY`를 등록합니다. `GEMINI_MODEL`은 선택 목록에 추가할 대안 모델 설정입니다. 화면의 기본 선택은 `gemini-3.5-flash-lite`입니다.

자막이 없으면 MP3 구간을 Gemini 요청에 직접 포함해 원래 언어로 전사합니다. 별도 Files API 업로드·대기·삭제를 사용하지 않습니다. 2분을 초과하는 오디오는 2분 단위로 분할합니다. 504 등 일시 오류는 제한된 횟수만 재시도하며, 전사가 계속 지연되면 해당 구간을 최대 두 번 더 분할합니다. Gemini 3.5 Flash-Lite는 `thinking_level=minimal`을 사용해 전사 지연을 줄입니다. 직접 전송하는 오디오는 8MB로 제한하며, 초과하면 전송 전 다시 인코딩합니다. 전사와 요약 과정에서 오디오와 텍스트가 Google로 전송됩니다. 긴 영상은 API 호출 횟수·비용이 증가하며 무료 할당량에서 요청이 제한될 수 있습니다.

## 배포 갱신 확인

제목 아래 **앱 1.2.2 · 처리 모듈 1.2.2**로 화면과 처리 코드의 버전을 함께 확인합니다. 실행 중인 처리 모듈과 디스크의 소스가 다르면 API 호출을 중지하고 재시작을 안내합니다. Streamlit Cloud에서 **Manage app → Reboot app** 후 새로고침하세요. 처리 코드는 `video_engine.py`에 있습니다.

Gemini 3.5 Flash-Lite의 모델 ID는 Google 공식 [시작 예제](https://github.com/google-gemini/cookbook/blob/main/quickstarts/Get_started_Generate_Content.ipynb)에서 확인했습니다. 기본 선택은 `gemini-3.5-flash-lite`입니다. 선택한 모델을 음성 전사와 요약에 모두 사용하고 화면에 표시합니다. 공식 문서에서의 지원과 현재 API 키의 사용 권한·할당량은 별개이므로 실제 호출은 해당 계정에서 확인해야 합니다.
